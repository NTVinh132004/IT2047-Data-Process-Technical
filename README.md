# mortgage-datavault

Lakehouse + Data Vault 2.0 trên Apache Spark cho phân tích rủi ro tín dụng khoản vay thế chấp
(Freddie Mac Single-Family Loan-Level Dataset, vintage 2019).

Tài liệu: [PRD](docs/PRD.md) · [Kế hoạch triển khai](docs/ke-hoach-trien-khai.md) · [Review](docs/review.md)

## Trạng thái

Đang ở giai đoạn 0 (cổng C0). Pipeline chưa chạy được.

## Dữ liệu

Dữ liệu không nằm trong repo. Tải từ trang Clarity của Freddie Mac rồi đặt vào:

```

data/raw/sample_2019/sample_perf_2019.txt
```
